Dam Screening Tool

Dam Data

The Dam Data page records the dam's identity, types, dimensions, key elevations and reservoir data, together with the justification for any value that differs from the National Inventory of Dams (NID). The user reaches it from Screening Information > Dam Data. For a dam taken from the NID, DST fills the page from the dam's NID record when the screening is created, and each value shows whether it still matches the NID. For a dam entered manually, the team enters every value.

Figure shows the page for an NID dam, and Table describes each numbered region.

Table: Dam Data page regions
#RegionDescription
1NID data barThe date of the NID record the screening uses, when DST last fetched it, and how many fields the team has changed. Shown only for an NID dam.
2Re-fetch from NIDCompares the screening with the current NID record (see Re-fetching from the NID).
3NID badgeThe value still matches the NID.
4DefinitionOpens the NID definition of the field.
5Required tagThe value is needed before the screening can be submitted.
6Edited badgeThe value differs from the NID. Selecting it offers to reset the value (see NID values and overrides).

8Dam data summaryThe page's summary tray (see Dam data summary).

Inputs on this page save automatically (see Saving): text and number fields when the user leaves them, and selections as soon as they are made. Changing any value clears the page's verification (see Human Verification) and can change other pages (see What a change affects). The Facilitator, Team Members and administrators can edit the page while the screening's inputs are open for editing; everyone else sees it read-only.

NID values and overrides​

For an NID dam, the label of every field filled from the NID carries a badge that shows whether the value still matches the NID:

  • NID — the value matches the NID record.
  • Edited — the team changed the value. Resting the pointer on the badge shows the NID value and the date DST fetched it.

To return a field to the NID value, the user selects its Edited badge. A panel opens with the Current value and the NID value (Figure). Reset to NID returns the field to the NID value, and Cancel closes the panel. Some fields reset together: Latitude and Longitude, the dam types, and the spillway types. When more than one of them changed, the panel lists each one under "Reset these fields to NID values?".

The page does not show the dam's hazard potential classification. For an NID dam, DST copies it from the NID, and a re-fetch can update it (Hazard Class in the comparison). It cannot be entered in DST, so a dam entered manually has none.

Justifying a changed value​

Each changed value requires a justification when the NID supplied a value for the field. The justification chip beside the field's label shows a pencil while the justification is missing and a check mark once it is written. To write one, the user selects the chip, which opens a box headed by the field name with the note "The NID value is" followed by the NID value (Figure), and enters the reason, up to 4,000 characters. The justification saves when the box closes. The same justifications can be written in the Dam data summary tray. A field the NID left blank needs no justification when the team fills it in.

A justification is kept when its field is reset to the NID value or re-fetched, and it is required again if the field is changed again. A missing justification leaves the Dam Data page Incomplete on the Submission Readiness page (see Submission Readiness). Writing or changing a justification clears the page's verification.

Re-fetching from the NID​

Re-fetch from NID brings the screening up to date with the current NID record and allows the team to choose which of its edits to keep. When the NID has changed a field this screening uses, a note titled "The NID has newer data for this dam" appears below the NID data bar, with the date of the NID update and the number of fields changed. The button is available to the Facilitator, Team Members and administrators while the screening's inputs are open for editing, for a dam with a Federal ID.

  1. 1The user selects Re-fetch from NID. DST opens a comparison below the NID data bar (Figure).
  2. 2For each field under Your edits, the user chooses Keep mine or Use NID, or sets every row at once with Keep all mine or Use NID for all.
  3. 3The user selects Apply to save the result, or Cancel to close the comparison without a change.

The comparison has two lists and a summary line:

  • NID updates — fields whose NID value changed and that the team has not edited, with the Current and NID values. Applying replaces them. The list can include NID fields the page does not show, such as Hazard Class, City, NID Height, USACE Dam or DSAC Class.
  • Your edits — fields the team changed, with Your value and the NID value. Keep mine is selected to start. "NID changed since your edit" marks a field whose NID value changed after the team edited it.
  • The summary line counts the updates that will apply, the edits kept and the edits that will be replaced. When nothing differs, it reads "No values differ from the NID. Applying updates this screening's NID record date."

Apply also updates the NID record date and the fetch date. Applying a comparison that changes any value clears the page's verification and has the same effects on other pages as editing those values. A change to USACE Dam changes who can be chosen as a new Facilitator for an Official screening (see Team management).

General information​

The General Information section identifies the dam (Table).

Country—OptionalChosen from a searchable list of countries.
State / Province—OptionalFor the United States, or when no country is chosen, a drop-down of state and territory abbreviations; for any other country, a text field.
County—OptionalThe county the dam is in.

Dam & spillway types​

The Dam & Spillway Types section records every dam type and spillway type present. Selecting a card selects its type, and selecting it again clears it. Both are required (Table). The dam types decide which cross sections, materials and potential failure modes apply to the screening on the Response pages.

Table: Dam and spillway type fields
FieldUnitsRequiredDescription
Dam Type—RequiredEvery type present, from Earth, Rockfill, Gravity, Arch, Buttress, Timber Crib, Masonry, Multi-Arch, Stone and RCC. The first type selected is the primary type.
Spillway Type—RequiredControlled, Uncontrolled, or both; or None. Selecting None clears Controlled and Uncontrolled, and selecting either of them clears None. While neither Controlled nor Uncontrolled is selected, the spillway crest elevation and storage of Key elevations & storage are unavailable.

The NID sometimes lists a dam only as "Concrete" or "Other". DST cannot use that value for failure mode screening and evaluation, so a note above the cards asks the team to select the specific dam type or concrete section type, and the page reports a required input until one is selected.

Physical data​

The dam's dimensions and location belong in the Physical Data section (Table). Lengths are in feet (ft) for a US Customary screening and meters (m) for an SI (Metric) screening.

Year Completed—RequiredA year from 1000 to 2100.
Spillway Widthft or mOptionalZero or greater.

The dam's location can also be set by selecting a point on the Overview map (see Setting the dam location).

Key elevations & storage​

The Key Elevations & Storage section lists the dam's design elevations, from the dam crest down to the streambed, each with the reservoir storage at that level (Table). Elevations are on the screening's vertical datum, for example ft-NAVD88, and storage is in acre-ft or m³. The stage-duration curve, the failure mode pages and the Operational Data charts start from these elevations; changing one of them on those pages requires a justification there. The question-mark button beside each level gives its definition.

Table: Key elevations and storage fields
FieldUnitsRequiredDescription
Dam Crest: Elevationft or mRequiredThe design elevation of the top of the dam, including a parapet wall that retains water. Two decimal places.
Dam Crest: Storage (Max storage)acre-ft or m³OptionalReservoir storage at the dam crest. Filled from the NID for an NID dam. Zero or greater.
Spillway Crest: Elevationft or mConditional: required when Controlled or Uncontrolled is selectedThe crest elevation of the principal spillway. Unavailable, and shown as "No spillway", while neither Controlled nor Uncontrolled is selected.
Spillway Crest: Storageacre-ft or m³OptionalStorage at the spillway crest. Unavailable while neither Controlled nor Uncontrolled is selected. Zero or greater.
Normal Pool: Elevationft or mRequiredThe elevation of the reservoir at its normal retention level. The default normal pool on the Stage Duration page.
Normal Pool: Storage (Normal storage)acre-ft or m³OptionalStorage at the normal pool. Filled from the NID for an NID dam. Zero or greater.
Streambed (zero storage): Elevationft or mOptionalThe elevation of the streambed at the dam, where the reservoir holds no storage. It may equal the normal pool for a dam that is normally dry.
Streambed (zero storage): Storageacre-ft or m³Read-onlyAlways 0.

Reservoir & safety​

The Reservoir & Safety section covers the reservoir's areas and the dam's Emergency Action Plan (EAP) status (Table). For an NID dam, the three EAP fields come from the NID and are read-only.

Table: Reservoir and safety fields
FieldUnitsRequiredDescription
Surface Areaacres or haOptionalThe reservoir surface area. Zero or greater.
Drainage Areasq mi or km²OptionalThe area draining to the dam. Zero or greater.
EAP Status—OptionalYes, No or Not Required. Read-only for an NID dam.
EAP Last Revised—OptionalThe date the EAP was last revised, entered as YYYY-MM-DD. Read-only for an NID dam, which shows the NID date.
EAP Last Exercise—OptionalThe date the EAP was last exercised, entered as YYYY-MM-DD. Read-only for an NID dam, which shows the NID date.

For a dam entered manually, an EAP date saves when the user leaves the field, and the field then shows it as a full date-and-time timestamp.

Dam data summary​

The Dam data summary tray at the bottom of the page brings every NID override and its justification together in one place and holds the page's supporting documents (Figure). Summary Tray describes how the tray opens and closes. For an NID dam, its status reads "No NID overrides", or counts the overrides and any that still need a justification, for example "2 NID overrides · 1 needs justification".

  • NID overrides (NID dams only, Required while any override exists) lists each changed field, with the NID value and the current value, for example "NID 100 → 98", and its justification. Each justification can be written or edited here; it saves when the user leaves the box. With no overrides, the section reads "Every value the NID supplied is unchanged."
  • Supporting documents links files from the screening's Documents to this page (see Supporting Documents).

Dam data messages​

The page messages button reports each missing required value as a required input (see Page Messages). When the key elevations are out of order against each other, DST shows a warning notice each time the page saves; the warnings never block submission. "Provide the Spillway Crest Elevation." appears only when Controlled or Uncontrolled is selected. When the only dam type is a general NID classification, the Dam Type message names it, "Concrete" or "Other".

The Dam Data page is Ready on the Submission Readiness page when every required value is present, every required justification is written and the page is verified.

What a change affects​

Because other modules draw on Dam Data, a change here can alter other pages:

  • Changing the Latitude or Longitude, on this page or on the Overview map, retrieves the seismic hazard data for the new location (see Seismic Hazard).
  • Changing the Normal Pool elevation changes the default normal pool on the Stage Duration page and can clear that page's verification (see Stage Duration).
  • Changing the dam types or the Dam Crest elevation can change which potential failure modes apply and update Failure Mode Screening (see Failure Mode Selection).
  • Changes to Dam Data can clear the verification of failure mode locations whose evaluation uses the changed values (see Verifying a location).

Common problems​

  1. Only the Facilitator, Team Members and administrators can edit it, and only while the screening's inputs are open for editing (see Input Lock).

  2. The dam has no Federal ID linking it to the NID. The button is also unavailable while a comparison is open; the user applies or cancels it first.

  3. DST could not reach the NID. The screening keeps its current values; the user selects Close and tries again later.

  4. DST could not find the dam's NID record.

  5. An NID override is missing its justification. The tray status reads "needs justification"; the user writes it from the field's chip or in the tray.

  6. The user selects the specific dam type cards.

  7. Neither Controlled nor Uncontrolled is selected under Spillway Type.

  8. Another user saved the page first. DST reloads the latest values; the user enters the change again if it is still wanted (see Editing Conflicts).
