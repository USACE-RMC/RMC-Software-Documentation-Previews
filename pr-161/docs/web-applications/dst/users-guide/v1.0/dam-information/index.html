Dam Screening Tool

Dam Information

The Dam Information page (Response > Dam Information) holds the physical description of the dam that the failure mode pages evaluate: the features of the embankment, the materials it is built from, its cross sections and the slopes of its abutments. The Failure Mode Screening page reads the embankment features, and each failure mode page reads the materials, cross sections and abutment slopes that apply to it.

This page describes the page and the list of cross sections. The editors that draw each cross section are described in Cross-Section Editors.

The Dam Information Page​

The sections the page shows depend on the dam types selected on the Dam Data page (see Dam Data), as

Table shows.

Table: Dam Information sections by dam type
Dam types on Dam DataSections shown
Earth, RockfillEmbankment Features; Materials, with the embankment materials table; Cross Sections, with Embankment sections; Abutment Slopes.
Gravity, Roller-Compacted ConcreteMaterials, with the concrete unit weight; Cross Sections, with Concrete sections.
Arch, Buttress, Timber Crib, Masonry, Multi-Arch, StoneCross Sections, with Named sections.

A dam with several dam types shows the sections of each. The dam types Concrete and Other select no sections. When no dam type that selects a section is chosen, the page shows only the note No dam type selected, which links to Dam Data, and has nothing to verify. When data exists for a dam type that is no longer selected, the note Some dam information is hidden explains that the data is retained, not deleted, and returns when that dam type is selected again.

Figure shows the top of the page for a dam with embankment and concrete sections, and Table describes each numbered region.

Table: Dam Information page regions
#RegionDescription

2Materials tableOne row per material (see Materials).

Inputs on this page save when the user leaves a field or makes a selection (see Saving); the cross-section drawings are the exception and save with the editors' Save button. The whole page is verified as one, and any change except to a reference image clears its verification (see Human Verification). When a change makes the results of a failure mode page out of date, DST clears those results and says so (see Automatic Calculation).

Embankment Features​

The Embankment Features section "(select all that apply)" shows one card for each feature, from upstream to downstream. Selecting a card marks the feature as present and shows its fields; selecting it again removes it. The information icon on most cards defines the feature.

Materials​

The Materials section holds the materials the cross sections are built from. For an embankment dam it holds the embankment materials table; for a concrete dam it holds the concrete unit weight; a dam of both kinds shows both side by side.

Embankment materials​

The table has two groups of rows. Embankment holds the main materials, labeled Material 01, Material 02 and so on. Drains & filters holds the drain and filter materials, Drain/Filter 01 and so on, and the Conduit Filter row that DST adds when the conduit has a diaphragm filter. Each material's color swatch matches the color of the zones drawn in it. Table lists the columns.

Table: Embankment material inputs
FieldUnitsRequiredDescription
Description—OptionalA name for the material, such as "Zone I - Impervious". Shown with the label in messages and drop-downs.
Material type—RequiredFor embankment materials: Silty Sand (SM), Silty Gravel (GM), Low Plasticity Silt (ML), Clayey Sand (SC), Clayey Gravel (GC), Silt and Clay (CL-ML), Lean Clay (CL), High Plasticity Silt (MH) or Fat Clay (CH). For drains and filters: Sand (SP, SW), Gravelly Sand (SP, SW), Sandy Gravel (GP, GW) or Gravel (GP, GW).
Gradation—OptionalYes or No: whether gradation test results are available. Available once a material type is chosen. Yes shows the Enter gradation button.
Dispersive—Conditional: embankment materialsYes or No: whether the material contains dispersive soils. The information icon explains how dispersivity is identified. Shows n/a for drains and filters.

Add material and Add drain or filter add a row. A screening holds at most 20 materials; when the limit is reached, the buttons are unavailable ("Material limit reached. Delete a material to add another."). Remove material (the trash icon) opens the Delete Material confirmation, which warns "This action cannot be undone."; the table always keeps at least one embankment material, and the Conduit Filter row cannot be deleted. A badge beside a row's label counts its errors.

Deleting a material does not delete what was drawn in it. In every embankment cross section, the zones and the seepage berm that used the material lose their material, and so does the core material the embankment generator remembers for the section. The zones then read Unassigned on the editor's Body tab, the section asks again for "Assign a material to this zone." or "Assign a material to the seepage berm.", and its card shows the type Earth Embankment until every zone has a material again. To restore the section, the user assigns another material in the editor and saves.

The page messages for the table include "Add at least one embankment material.", "Select the material type for [material].", "Indicate whether [material] contains dispersive soils." (required inputs) and "[material]: gradation is marked available but no gradation rows have been entered." (a warning).

Gradation​

Enter gradation opens the gradation dialog for the material, headed, for example, "Gradation — Material 01 — Zone I - Impervious" (Figure). It holds two tables, Coarse Band and Fine Band, and a chart of both curves. On a narrow screen, Tables and Plot switch between the tables and the chart. Each table has the columns:

  • Sieve Size: a standard sieve chosen from the list, or Custom or Hydrometer for a size entered by hand.
  • D (mm): the particle size. DST fills it for a standard sieve; the user enters it for Custom and Hydrometer.
  • Coarse (%) or Fine (%): the percent passing, between 0 and 100.

The tables work like the other tables in DST (see Tables) and save as the user edits. The issue chip in the dialog's title lists the gradation's messages: the errors "[material] ([coarse or fine] gradation): particle size at row [n] must be greater than zero." and "[material] ([coarse or fine] gradation): percent passing at row [n] must be between 0 and 100.", and the warnings "[material] ([coarse or fine] gradation): particle sizes are not in decreasing order — check the curve." and "[material] ([coarse or fine] gradation): percent passing increases as particle size decreases — check the curve." The × closes the dialog.

Each band holds up to 500 rows. A gradation with a longer table is not saved, and DST reports "A gradation table can hold at most 500 rows."

The Concrete unit weight (pcf) card holds the unit weight of the concrete. The default is a deterministic 145 pcf. Distribution chooses Deterministic, Triangular, PERT, Uniform or Normal, and the boxes beside it change to match, as

The card's page messages are the required inputs "Enter the concrete unit weight.", "Enter the minimum, most likely, and maximum concrete unit weight.", "Enter the minimum and maximum concrete unit weight." and "Enter the mean and standard deviation of the concrete unit weight.", and the errors "Concrete unit weight: the most likely value must fall between the minimum and maximum.", "Concrete unit weight: the minimum must be less than the maximum." and "Concrete unit weight: the standard deviation must be greater than zero."

Cross Sections​

The Cross Sections section lists the dam's cross sections as cards, grouped under Embankment, Concrete and Named (Figure). Only the groups the dam types allow appear. Within each group the cards keep the order the sections were added. At least one cross section is required ("Add at least one cross section."), and a screening holds at most 100.

Adding a cross section​

Each group ends with a dashed card: Add Earth Section, Add Concrete Section or Add Named Section. Selecting it adds a section. A new embankment or concrete section opens its editor at once (see Opening an Editor). When the screening has more than one named-only dam type, Add Named Section first asks "Which dam type does this section represent?" with a button for each dam type.

Section cards​

Each card's header holds the section's name, its badges and its type, and its body holds the drawing:

  • Name. The name or station range, or "Unnamed cross section". Selecting the name ("Rename") makes it editable, up to 200 characters; Escape restores the previous name. A section needs a name ("Provide a name or station range for the cross section."), and two sections with the same name show the warning "More than one cross section is named '[name]' — rename one so failure modes can tell them apart."
  • Issue badge. A count of the section's errors, red, or of its warnings, amber. Selecting it lists them.
  • Crest justification chip. Shown when the section's drawn crest differs by more than 0.5 (in the screening's elevation units) from the dam crest elevation on Dam Data, or for a concrete overflow section from the spillway crest. It explains the difference, for example "This crest (1250.80 ft-NAVD88) is 0.80 ft above the Dam Data dam crest (1250.00).", and Add justification opens a box for the reason. The drawn crest still governs every calculation. The section header counts the sections still missing a justification, for example "2 crests need justification".
  • Type. The section type: Zoned, Homogeneous Earthfill or Earth Embankment for an embankment section (the first two once every zone has a material), Concrete Overflow (Gated), Concrete Overflow (Ungated) or Concrete Non-Overflow, or Named.
  • Drawing. A thumbnail of the section. Selecting it opens the section's editor.

A named section has no drawing. Its card shows the dam type it represents and a single box, "Describe this section (optional)", of up to 500 characters, which saves when the user leaves it. A named section needs its dam type ("Select the dam type this section represents.").

Copying and deleting​

The menu at the right of a card header offers:

  • Copy adds a copy of the section. The copy is named after the section with " (Copy)" added and is placed last in its group. It carries the section's drawing, description and crest justification, and its reference image together with the image's calibration, so tracing can continue on the copy without calibrating again.
  • Copy at new base elevation, for an embankment section with zones, opens a dialog that copies the section cut off at a new, higher base. The user enters New base elevation (the hint gives the allowed range, "Above [x] and below [y] ft") and a Name, which defaults to the section name followed by "@ El." and the elevation. A preview shows the original and the copy, with the new Height and Base width beside their former values, and Review before creating lists anything DST changed, such as a seepage berm that was not carried over. Create adds the copy; Create and edit adds it and opens its editor; Cancel closes the dialog.
  • Delete opens the Delete Cross Section confirmation: "Are you sure you want to delete [name]? This action cannot be undone."

A screening holds at most 100 cross sections; a copy beyond that is refused with "A screening can hold at most 100 cross sections."

Copying at a new base elevation​

Copy at new base elevation makes a shorter copy of a section already drawn, with its base raised, for a station where the foundation stands higher. DST cuts every zone of the source at the new base and keeps what lies above it; a zone whose base is already above the new base is kept as it is. A drain or filter layer that runs along the old base is raised with the base, so the copy keeps its drainage at its foundation. The source section is not changed, and the copy is placed right after it.

DST builds the preview when the user leaves the New base elevation box. The preview draws the copy over the original, and it zooms and pans like the embankment generator's preview (see Generating a simple embankment). The Name holds up to 200 characters; clearing it restores the default name. The copy does not carry the source's reference image.

DST refuses a copy it cannot make, and shows the reason under the New base elevation box:

  • "Draw this cross section before copying it at a new base elevation." when the section has no zones.
  • "Assign a material to every zone before copying this cross section at a new base elevation."
  • "Fix this cross section so its zones form one closed shape before copying it at a new base elevation."
  • "Enter a base elevation above [x] and below [y]." for an elevation outside the allowed range.
  • "This cross section can't be copied at El. [x]: "[zone]" would surround another zone."
  • "This cross section could not be cut cleanly at El. [x]. Copy it and edit the copy instead."
  • "The copy would need more than 200 points or 20 zones. Copy the section and edit it instead."

A copy DST can make may still need a look. Review before creating lists each change DST made to the drawing:

  • "The seepage berm was not carried over. Draw it again if it applies at this location."
  • ""[zone]" is entirely below the new base and was removed."
  • "Only a sliver of "[zone]" was left above the new base, so it was merged into the zone next to it."
  • "Only a sliver of "[zone]" is left above the new base. Check whether to keep it." The sliver is kept.
  • ""[zone]" was cut into [n] separate pieces." Each piece becomes its own zone, named "[zone] (1)", "[zone] (2)" and so on, with the zone's material.
  • "A small piece of "[zone]" was cut off from the rest of the section by the new base and was removed."
  • "Part of [drain] along the base was trimmed where it meets the outside of the new section (about [n]% of it). Check its ends."

The notices are advice, not errors: Create and Create and edit stay available once the preview matches the entered elevation and the copy has a name, and the copy can be corrected in its editor afterward.

Reference images​

An embankment or concrete section can hold a reference image: a drawing or screenshot of the section placed under its editor's canvas for tracing. The image saves with the screening as soon as it is added, changed or removed, and these changes do not clear the page's verification. Images are added and calibrated in the editors (see Reference Images).

Abutment Slopes​

The Abutment Slopes section describes the slopes of the left and right abutments, looking downstream (Figure). Between the two sides, a diagram titled "Profile view of the dam, looking downstream" labels each input; it is an "Illustration of the inputs only — not this dam, not to scale", and it adds a bench for each bench the user enters. Messages about the abutments appear in a note at the top of the section.

Table lists the inputs of each side.

Table: Abutment slope inputs
FieldUnitsRequiredDescription
Top slope, θLT and θRTdegRequiredThe slope of the abutment just below the crest, or above the highest bench, in degrees from horizontal. Greater than 0 and no more than 90. The slider sets it in steps of 5° from 5° to 90°; the box takes any value to 0.1°.
Benches—OptionalAdd bench adds a bench, up to five per side, numbered from the top down. The trash button deletes a bench.
Slope below Bench n, θL1 and so ondegConditional: for each benchThe slope from that bench down to the next bench or the valley floor. Greater than 0 and no more than 90.

The information icons on the fields describe how potential failure mode PFM-02 uses the slopes. The section's messages are "Provide the [left or right] abutment top slope.", "Provide the slope below Bench [n] on the [side] abutment." (required inputs), and "The [side] abutment top slope must be greater than 0 and no more than 90 degrees." and "The slope below Bench [n] on the [side] abutment must be greater than 0 and no more than 90 degrees." (errors).

PFM-02 locations​

The abutment slopes also decide where PFM-02 is evaluated. Each saved change to the section brings the PFM-02 locations into line with the slopes and benches (see Location and Cross Section):

  • Abutments. An abutment whose top slope is between 15° and 65° is a location, Left Abutment or Right Abutment. When its top slope moves outside that range, DST deletes the location with its inputs and results.
  • Benches. Every bench is a location, for example Left Abutment Bench 1, whatever the top slope. DST matches bench locations to benches by number, so deleting a bench deletes the location of that side's last bench, with its inputs and results. The benches below a deleted bench move up a number and take over the locations of their new numbers, with the inputs entered there; after deleting any bench but the last, the user reviews those locations.
  • Cutoff walls. When the cutoff or seepage barrier wall is marked At crest and Failure Mode Screening question 7a says it ties into an abutment, DST hides that abutment's locations instead of deleting them. They return, with their inputs, when the tie is removed.

DST adds new locations only while PFM-02 is selected for evaluation. When no abutment or bench yields a location, PFM-02 keeps a single location, Location 1, that the team describes itself.
