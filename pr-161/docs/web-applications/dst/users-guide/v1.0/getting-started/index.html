Dam Screening Tool

Getting Started

This page covers obtaining an account and signing in, finding and opening screenings on the Dashboard, creating and copying screenings, managing a screening team and updating the Profile page. Working in DST covers the work within an open screening: navigation, saving, verification and the other behaviors shared by every screening page.

Signing In​

DST's home page is public. Request Access asks for an account, and Log In opens the Log In dialog (Figure). Following a link to a DST page while signed out opens the Log In dialog, and after signing in the user goes on to the page the link pointed to.

Requesting an Account​

A DST administrator approves every DST account. A person without an account selects Request Access on the home page and completes the Request an Account dialog. Every field is required (Table).

Table: Request an Account fields
FieldDescription
First NameUp to 100 characters.
Last NameUp to 100 characters.
EmailThe address DST uses to identify the user and send email, up to 254 characters.
Organization TypeFederal, State, Local, Private or Academic.
OrganizationThe name of the user's agency or company, up to 200 characters.
PasswordAt least 15 characters, with at least one uppercase letter, one lowercase letter, one number and one special character.
Confirm PasswordThe same password again.

A checklist under the password fields marks each requirement as it is met and flags passwords match while the two entries differ. Show reveals what was typed. Submit becomes available once every field is filled, the password meets the requirements and the two passwords match. DST then confirms "Account request submitted" and emails the user when the request is received and again when it is approved or denied. Once approved, the user signs in with the email address and password from the request.

Logging In​

Log In offers two ways to sign in:

  • Sign in with Login.gov sends the user to Login.gov and back to DST signed in. The first time, DST links the Login.gov identity to the DST account with the same email address.
  • Email and password. The user selects or sign in with email, enters Email and Password, and selects LOG IN. The email form opens on its own the next time for a user who last signed in this way.

After signing in, the user arrives at the Dashboard, or at the page a link pointed to. Messages about a refused sign-in are listed in Common Problems.

Forgotten Passwords and Locked Accounts​

DST administrators handle password resets and account unlocks:

  • Forgot password? beside the Password field opens the Forgot Password dialog. The user enters the account's email address and selects Submit Request. Once an administrator approves the request, DST emails the user a temporary password. At the next sign-in the Set New Password dialog requires a new password: the user enters New Password and Confirm Password and selects Update Password, or selects Log Out.
  • Locked account. After five failed sign-in attempts the Log In dialog shows the Account Locked view, with I FORGOT MY PASSWORD and REQUEST UNLOCK. The account stays locked until an administrator acts on the request, and DST emails the user when the unlock request is received and again when the account is unlocked.

A user who signs in only with Login.gov has no DST password; Forgot password? sets one if the user also wants to sign in by email.

Staying Signed In​

A session ends after 15 minutes without activity. Two minutes before it ends, a Session Expiring notice counts down; Stay Logged In keeps the session open. When a session ends, the Session Expired dialog asks the user to sign in again over the page the user was on, so work continues where it stopped. Logout in the avatar menu ends the session (see The Site Header).

The Dashboard​

The Dashboard is the starting point for finding, opening and creating screenings and for reaching review assignments. It opens after signing in, and Home or the USACE castle logo in the site header returns to it. Figure shows the Dashboard, and Table describes each numbered region.

Table: Dashboard regions
#RegionDescription
GreetingThe user's first name and the current date.
TabsMy Screenings, My Reviews and Search Catalog. The My Reviews badge counts the user's current review assignments.
FiltersStatus, Type and Per page. Administrators also see an All screenings toggle.
SearchSearches the user's screenings by screening name, dam name, description or screening ID.
New ScreeningOpens the New Screening dialog.
Screenings tableThe screenings the user facilitates, works on or can view.
Status badgeWhere the screening is in its workflow.
Row actionsOpens the actions available for that screening.

When the DST administrators have announcements, an information ticker appears below the greeting; its arrows move between messages, and × hides it until the browser tab is closed. Site alerts appear at the top of the Dashboard (see Site Alerts).

My Screenings​

The My Screenings tab lists every screening on which the user is the Facilitator, a Team Member or a Viewer. Screenings on which the user is only a reviewer appear on the My Reviews tab. Selecting a screening's name opens it. Table describes the columns.

Table: My Screenings table columns
ColumnShows
IDThe screening number, which is unique across DST.
ScreeningThe screening name, which opens the screening.
DamThe dam name. An NID badge marks a dam linked to the National Inventory of Dams and opens its NID record.
TypeOfficial or Testing.
StatusThe screening status (see below).
FacilitatorsThe Facilitator, with a count when there is more than one.
Created ByThe user who created the screening.
ModifiedHow long ago the screening was last changed, or the date for changes older than a week.

Selecting a column heading sorts the table by that column, and selecting it again reverses the order. The table opens sorted by Modified, newest first, and Status sorts in workflow order. On phones and tablets the table appears as cards, which cannot be sorted.

A screening's Type is set when it is created:

  • Official: a screening of record that can be submitted for review and approval.
  • Testing: a practice screening. It cannot be submitted for review, never appears in the Search Catalog, and shows N/A for its status.

An Official screening shows one of these statuses:

  • In Progress: the screening team is entering and evaluating the screening. A screening also returns to In Progress if a review lead rejects it.
  • Submitted: the Facilitator has submitted the screening. The first review level starts immediately, so this status is usually brief.
  • Under Review: a review level is in progress. Inputs are locked except during a review level's resolution period.
  • Complete: every review level is approved.
  • No Facilitator: the screening lost its Facilitator, for example because the Facilitator's account was deactivated. Inputs stay locked until a new Facilitator is assigned.

The Review Lifecycle describes the review behind these statuses.

Finding a Screening​

The filter bar narrows the list:

  • Status: All, In Progress, Submitted, Under Review, Complete or No Facilitator.
  • Type: All, Official or Testing.
  • Per page: 15, 25 or 50 screenings per page.
  • Search: matches any part of the screening name, dam name or description; a whole number also matches that screening ID.
  • All screenings (administrators only): lists every screening in DST.

Each active filter appears as a chip; × on a chip removes that filter, and Clear all removes them all. When more screenings match than fit on one page, the page controls below the table move between pages.

tip

Pressing / anywhere on the Dashboard moves the cursor to the search box, and pressing n opens the New Screening dialog.

Actions on a Screening​

The ⋮ button at the end of each row opens the screening's actions (Figure). Only the actions the user is permitted to take appear (Table).

Table: Row actions
ActionAvailable toDoes
Open ScreeningEveryone on the screeningOpens the screening.
Manage TeamThe Facilitator and administratorsOpens the Manage Team dialog (see Managing the Screening Team).
RenameThe Facilitator and administrators, while In Progress or TestingChanges the screening name (see Renaming a Screening).
CopyEveryone on the screeningCreates a new screening from this one (see Copying a Screening).
DeleteThe Facilitator and administrators, while In Progress or Testing; administrators only after submissionRemoves the screening from DST for everyone. An administrator can restore it.

Delete asks for confirmation; the dialog notes "This action can be undone by an administrator."

When There Are No Screenings​

A user with no screenings sees a Create Your First Screening button instead of the table (Figure). If filters hide every screening, the table reads "No screenings match your filters" with a Clear filters link.

My Reviews​

The My Reviews tab lists the review levels on which the user is a reviewer (Figure). Assignments are grouped into three tables:

  • Active Reviews: review levels in progress now, or about to start because every earlier level is approved. Rows that need the user's action come first.
  • Upcoming Reviews: review levels that start after an earlier level finishes.
  • Completed Reviews: approved review levels, newest first. The list covers the last 90 days; the Show drop-down extends it to 6 months, a year, or all.

A user with no review assignments sees "No review assignments. You'll see screenings here when you're assigned as a reviewer." Table describes the columns.

Table: My Reviews columns
ColumnShows
ScreeningThe screening name, with its screening status.
DamThe dam name.
Your ReviewThe review level the user is assigned to.
Review StatusThe level's phase: Not Started, Review Period, Resolution, Backcheck, Acknowledged or Approved.
Your StatusPending, Participated or Unresponsive. A reviewer who has not participated is marked Unresponsive when the review period ends.
CommentsOpen comments out of the total for the current review cycle.
Next StepWhat happens next. A blue dot marks a step that waits on the user.
Active LevelUpcoming Reviews only: the level currently in progress.
CompletedCompleted Reviews only: the date the level was approved.

Selecting a row opens the screening's Review page; Review Levels describes the reviewer's steps there. The tab loads its list the first time it is opened, so reloading the page shows activity that happened since.

Search Catalog​

Every Official screening in DST is searchable from the Search Catalog tab, including screenings the user has no access to, and access to any of them can be requested there from the screening's Facilitator (Figure). Table describes each numbered region. Testing screenings never appear in the catalog.

Table: Search Catalog regions
#RegionDescription
Pending access requestsScreenings the user has asked to access and the Facilitator has not yet answered. Shown only when such requests exist.
Browse screeningsEvery other Official screening, sorted by dam name. A row the user can already open ends in an arrow that opens the screening.
SearchMatches the screening name, dam name, owner name, NID ID or Federal ID; a whole number matches that screening ID.
Request accessThe user has no access; the key opens the Request Access dialog.
Request pendingThe request is waiting on the Facilitator.

The Status drop-down and the search box filter both lists, Per page sets the length of the browse list (25, 50 or 100), and selecting a column heading sorts it. An approved request moves out of the pending list without a reload.

Requesting Access to a Screening​

A user asks for access to a screening from its row in the browse list:

  1. 1Select the key icon at the end of the screening's row.
    Result: The Request Access dialog opens.
  2. 2Optionally enter a Reason for request (up to 1,000 characters), such as the user's role for the dam, then select Send Request.
    Result: DST confirms "Access request sent. The screening Facilitator will review it." The screening moves to Pending access requests, and the Facilitator receives a notification and an email.
  3. 3The Facilitator, or an administrator, approves or denies the request on the screening's Screening Management page. Approval grants Viewer access; either way, the user receives a notification and an email.

Access Requests describes approving and denying requests. A request cannot be withdrawn from the Dashboard. After a denial the screening returns to the browse list and the user may request access again. A request for a screening with status No Facilitator waits until a Facilitator is assigned.

Creating a Screening​

Any signed-in user can create a screening. The user selects + New Screening on the My Screenings tab (or Create Your First Screening on an empty Dashboard), or presses n on the Dashboard. The New Screening dialog opens with Vertical Datum set to NAVD88 and every other field empty.

Figure shows the dialog completed for a dam from the National Inventory of Dams (NID), and Table describes each field.

Table: New Screening fields
FieldRequiredDescription
TypeRequiredOfficial or Testing (see My Screenings).
Screening NameRequiredUp to 200 characters, for example "FY28 Hollowbrook Dam Screening".
DamRequiredThe dam being screened, found in the NID or entered by name (see Choosing the Dam).
USACE FacilitatorConditionalAppears for a USACE dam unless the Type is Testing, and is required for an Official screening (see USACE Dams).
Vertical DatumRequiredNAVD88, preselected, or Other; Other adds a box for the datum name (up to 50 characters), for example NGVD29.
UnitsRequiredUS Customary or SI (Metric). A dam taken from the NID is fixed at US Customary.
DescriptionOptionalThe purpose of the screening, up to 2,000 characters.

Create becomes available once every required field is complete and the dam's NID record has finished loading.

caution

Vertical Datum and Units cannot be changed after the screening is created.

Selecting Testing as the Type adds the note "Testing screenings are for practice and cannot be submitted for review or produce official reports." and removes the USACE Facilitator requirement (Figure). The same figure shows the datum name box that appears when Vertical Datum is Other, which is how a screening on NGVD29 or any datum other than NAVD88 is entered.

Choosing the Dam​

The Dam field searches the NID as the user types, by dam name, state, NID ID or county. Each match shows the dam's Federal ID and name with its county and state, and the list holds up to 15 dams. The last choice is always Use "…" as entered, for a dam that is not in the NID (Figure).

Many dams share a name. With four or more characters typed, dams whose name matches the text exactly come first, tallest first, followed by names that begin with the text and then other matches. Typing the full name, such as "Farmington Dam", therefore lists every dam of that name first, and the county and state tell them apart (Figure).

  • Selecting an NID dam links the screening to that NID record. The field reads the dam name followed by "— NID linked", DST loads the record ("Loading NID data..."), and Units is fixed at US Customary. On Create, DST copies the dam's NID data into the screening.
  • Selecting Use "…" as entered, or leaving the field with text typed and nothing selected, creates a dam entered manually. DST notes that the screening will not be linked to the NID and that the dam information will be entered manually (Figure).

The × on the dam chip clears the selection. Cancel closes the dialog without creating anything. Video shows a search: the matches appear as the name is typed, and selecting an NID dam links it, fixes Units at US Customary and, for a USACE dam, adds the USACE Facilitator field.

USACE Dams​

An Official screening of a dam owned by USACE needs a USACE Facilitator. Selecting a USACE dam from the NID adds the USACE Facilitator field unless the Type is Testing (Figure). The user searches the members of the USACE Facilitators group by name or email and selects a person; Change replaces the selection.

The selected Facilitator becomes the screening's Facilitator and is notified, and the user who created the screening joins its team as a Team Member. For every other screening, including any Testing screening, the user who creates it becomes its Facilitator.

After the Screening Is Created​

DST opens the new screening's Screening Information page. Every new screening starts with two review levels, Level 1 and Level 2. When the dam has a latitude and longitude, DST retrieves its seismic hazard data during creation, and reports a warning only if that retrieval has a problem. DST also collects reservoir data for the stage-duration curve in the background, which may take a few minutes to appear on the Stage Duration page.

Managing Screenings​

From the Dashboard, the Facilitator manages the screening team and renames the screening until it is submitted, and anyone on the screening can copy it.

Managing the Screening Team​

Manage Team in a screening's row actions opens the Manage Team dialog (Figure).

Availability

The screening's Facilitator and administrators only.

  • Facilitator: shows the screening's Facilitator. An administrator can select Replace to assign a different Facilitator while the screening is In Progress or Testing; the previous Facilitator loses access to the screening.
  • Team Members: the role drop-down switches a person between Team Member and Viewer, and the remove icon removes the person from the screening.
  • Add Member: the user searches active users by name or email, chooses the role in the drop-down, and selects + Add as Team Member or + Add as Viewer on the person.

Every change takes effect immediately, with no confirmation step. Reviewers are assigned to each review level on the Screening Management page instead (see Review Configuration).

Availability

While a screening is under review, Team Members and Viewers can still be added and removed, but the Facilitator stays fixed. Once a screening is Complete, or while it needs a Facilitator, only Viewer access can be changed.

The dialog states which of these applies.

Copying a Screening​

Copy creates a new screening from an existing one.

Availability

Anyone on the screening.

The Copy Screening dialog names the copy "(Copy)" followed by the original name and asks for its Type, which defaults to the original's. The user becomes the Facilitator of the copy, except for an Official copy of a USACE dam, which needs a USACE Facilitator (see USACE Dams).

A copy holds only the screening's starting information:

  • the description, vertical datum and units;
  • every Dam Data value, with the NID link, the record of which values differ from the NID and their justifications;
  • the documents, each keeping its links to pages except links to failure mode locations.

Everything else starts empty: Operational Data curves, Hazards, the Response pages, Consequences, Risk Analysis and Major Findings. Its Dam Data is unverified. Its team holds only its Facilitator (and, for an Official copy of a USACE dam with a different USACE Facilitator, the user who made the copy as a Team Member). The copy has none of the original's review levels, reviewers or review history; it starts with its own Level 1 and Level 2. DST confirms "Screening copied" and opens the copy on its Screening Information page.

Renaming a Screening​

Rename opens a dialog with the screening's current name. The user edits the name (up to 200 characters) and selects Rename; DST confirms the new name. If another user changed the screening at the same moment, DST refreshes the page without applying the rename, and the user renames it again.

Availability

A screening can be renamed only while it is In Progress or Testing.

The Profile Page​

The user's name and password are changed on the Profile page. View Profile in the avatar menu of the site header opens it (Figure).

  • Personal Information: First Name and Last Name save when the user leaves the field, and Saving… appears while a save is in progress. Email, Organization Type and Organization cannot be changed here.
  • Change Password: the user enters Current Password, then New Password and Confirm New Password, which must meet the same requirements as a new account's password and differ from the current one, and selects Change Password. DST confirms "Password changed".

Common Problems​

The messages and blocked controls a user may meet when signing in, creating a screening or managing screenings are listed below, with their causes and resolutions.

  1. Cause. The email address or password is wrong. The message gives the attempts remaining.

    Resolution. Retype the entries (Show reveals the password), or use Forgot password?.

  2. Cause. Five sign-in attempts failed.

    Resolution. Select I FORGOT MY PASSWORD or REQUEST UNLOCK and wait for an administrator.

  3. Cause. Too many sign-in attempts came from one location in a short time.

    Resolution. Wait, then sign in again.

  4. Cause. The account has no DST password.

    Resolution. Use Sign in with Login.gov, or use Forgot password? to set a password.

  5. Cause. No DST account uses the email address of the Login.gov identity.

    Resolution. Complete the Request an Account dialog, which opens with the name and email address filled in.

  6. Cause. Login.gov sign-in is not set up for this site.

    Resolution. Sign in with email and password; the email form opens automatically.

  7. Cause. The session had no activity for 15 minutes.

    Resolution. Sign in again; the page the user was on stays open.

  8. Cause. A required field is empty, the NID record is still loading ("Loading NID data..."), or an Official USACE dam has no USACE Facilitator.

    Resolution. Complete the required fields, wait for the NID record, or choose a USACE Facilitator. A Testing screening needs none.

  9. Cause. The USACE Facilitators group has no members.

    Resolution. Ask an administrator to add a member, or create a Testing screening.

  10. Cause. The text matches no dam name, state, NID ID or county.

    Resolution. Check the spelling or search by NID ID, or select Use "…" as entered for a dam not in the NID.

  11. Cause. DST cannot reach the NID.

    Resolution. Try again later. A dam entered manually is not linked to the NID.

  12. Cause. The screening has been submitted. Its name stays fixed through review, and only an administrator can delete it.

    Resolution. Ask an administrator.

  13. Cause. Only the Facilitator and administrators manage the team.

    Resolution. Ask the Facilitator to make the change.

  14. Cause. Testing screenings never appear in the catalog.

    Resolution. Find it on the My Screenings tab, if the user is on its team.

On the Profile page, an account that signs in only with Login.gov reports "This account has no password to change. Use 'Forgot password?' to set one." when Change Password is submitted.
