Dam Screening Tool

Getting Started

Every session in the Dam Screening Tool (DST) begins on the Dashboard. The Dashboard lists the screenings the user works on, the review assignments the user holds, and a catalog of every official screening in DST. From the Dashboard the user creates new screenings, opens existing ones, manages each screening's team, and requests access to screenings owned by others.

This chapter describes the Dashboard and the actions available from it. Working inside a screening — navigation, automatic saving, verification and the other behaviors shared by every screening page — is described in Chapter 4, Working in DST.

The Dashboard​

The Dashboard opens after the user signs in, and the user returns to it at any time by selecting Home in the site header or the USACE castle logo. Figure shows the Dashboard for a user assigned to several screenings, and Table describes each numbered region.

Table: Dashboard regions
#RegionDescription
1GreetingA greeting with the user's first name and the current date.
2Information tickerAnnouncements from the DST administrators. Each message advances on its own; the arrows and dots move between messages, and × hides the ticker for the rest of the browser session.
3TabsMy Screenings, My Reviews and Search Catalog. The My Reviews badge counts the user's current review assignments.
4FiltersStatus, Type and Per page drop-downs. Administrators also see an All screenings toggle.
5SearchSearches the user's screenings by screening name, dam name, description or screening ID.
6New ScreeningOpens the New Screening dialog.
7Screenings tableThe screenings the user facilitates, works on or can view.
8Status badgeWhere the screening is in its workflow.
9Row actionsOpens the actions available for that screening.

Administrators can also publish site alerts, which appear in a colored band at the top of the Dashboard. An alert with an × can be dismissed; it returns the next time the page loads.

My Screenings​

The My Screenings tab lists every screening on which the user is the Facilitator, a Team Member or a Viewer. Screenings on which the user is only a reviewer appear on the My Reviews tab instead. Selecting a screening's name opens that screening.

Table: My Screenings table columns
ColumnShows
IDThe screening number, which is unique across DST.
ScreeningThe screening name, which opens the screening.
DamThe dam name. An NID badge marks a dam linked to the National Inventory of Dams and opens its NID record.
TypeOfficial or Testing.
StatusThe screening status (see below).
FacilitatorsThe Facilitator, with a count when there is more than one.
Created ByThe user who created the screening. Shown only on wide screens.
ModifiedHow long ago the screening was last changed, or the date for changes older than a week.

Selecting a column heading sorts the table by that column, and selecting it again reverses the order. The table opens sorted by Modified, newest first. Status sorts in workflow order rather than alphabetically.

A screening's Type is set when it is created:

  • Official — a formal screening that can be submitted for review and approval.
  • Testing — a practice screening. A Testing screening cannot be submitted for review, never appears in the Search Catalog, and shows N/A for its status.

An Official screening shows one of these statuses:

  • In Progress — the screening team is entering and evaluating the screening. A screening also returns to In Progress if a review lead rejects it.
  • Submitted — the Facilitator has submitted the screening. Submission starts the first review level immediately, so this status is usually brief.
  • Under Review — one of the screening's review levels is in progress. Inputs are locked except during a review level's resolution period.
  • Complete — every review level is approved.
  • Needs Facilitator — the screening lost its Facilitator, for example because the Facilitator's account was deactivated. Inputs stay locked until an administrator assigns a new Facilitator.

The review process behind these statuses is described in Chapter 27, Review.

Finding a screening​

The filter bar narrows the list:

  • Status — All, In Progress, Submitted, Under Review, Complete or Needs Facilitator.
  • Type — All, Official or Testing.
  • Per page — 15, 25 or 50 screenings per page.
  • Search — matches any part of the screening name, dam name or description, and a whole number also matches that screening ID. Pressing the / key moves the cursor to the search box.
  • All screenings (administrators only) — lists every screening in DST, not only the administrator's own.

Each active filter appears as a chip below the bar; × on a chip removes that filter, and Clear all removes them all. When more screenings match than fit on one page, the page controls below the table move between pages.

Actions on a screening​

The ⋮ button at the end of each row opens the screening's actions (Figure). Only the actions the user is permitted to take appear.

Table: Row actions
ActionAvailable toDoes
Open ScreeningEveryone on the screeningOpens the screening.
Manage TeamThe Facilitator and administratorsOpens the Manage Team dialog (see Managing the screening team).
RenameThe Facilitator and administrators, while In Progress or TestingChanges the screening name.
CopyEveryone on the screeningCreates a new screening from this one (see Copying a screening).
DeleteThe Facilitator and administrators while In Progress or Testing; administrators only after submissionRemoves the screening from DST.

Rename and Delete disappear once a screening is submitted: its name stays fixed through review, and only an administrator can delete it.

Delete asks for confirmation. A deleted screening disappears for everyone, but it is not erased; an administrator can restore it.

When there are no screenings​

A user with no screenings sees an empty Dashboard with a Create Your First Screening button (Figure). The filter bar is hidden until the user has at least one screening. If filters hide every screening, the table is replaced by "No screenings match your filters" and a Clear filters link.

My Reviews​

The My Reviews tab lists every review level on which the user is a reviewer (Figure). It is organized into three tables:

  • Active Reviews — review levels in progress now, or about to start because every earlier level is approved. Rows that need the user's action are listed first.
  • Upcoming Reviews — review levels that will start after an earlier level finishes.
  • Completed Reviews — approved review levels, newest first. The Show drop-down sets how far back the list reaches: the last 90 days (the default), 6 months, a year, or all.
Table: My Reviews columns
ColumnShows
ScreeningThe screening name, with its screening status beneath.
DamThe dam name.
Your ReviewThe review level the user is assigned to.
Review StatusThe level's phase: Not Started, Review Period, Resolution, Backcheck or Approved.
Your StatusPending, Participated or Unresponsive. A reviewer who has not participated is marked Unresponsive when the review period ends.
CommentsOpen comments out of the total for the current review cycle.
Next StepWhat happens next. A blue dot marks a step that waits on the user.
Active LevelUpcoming Reviews only: the level currently in progress.
CompletedCompleted Reviews only: the date the level was approved.

Selecting a row opens the screening's Review page. The steps a reviewer takes there are described in Chapter 27, Review. The My Reviews tab loads its list the first time it is opened; reloading the page shows activity that happened since.

Search Catalog​

The Search Catalog tab lists every official screening in DST, including screenings the user has no access to (Figure). It lets a user find a screening of interest and ask its Facilitator for access. Testing screenings never appear in the catalog.

Table: Search Catalog regions
#RegionDescription
1Pending access requestsScreenings the user has asked to access and the Facilitator has not yet answered. Shown only when such requests exist.
2Browse screeningsEvery other official screening, sorted by dam name.
3SearchMatches the screening name, dam name, owner name, NID ID or Federal ID, and a whole number matches that screening ID.
4Open screeningThe user already has access; the arrow opens the screening.
5Request accessThe user has no access; the key opens the Request Access dialog.
6Request pendingThe request is waiting on the Facilitator.

The Status drop-down and the search box filter both the pending requests and the browse list, and Per page sets the length of the browse list (25, 50 or 100). The catalog refreshes itself every 45 seconds while it is open, so an approved request moves out of the pending list without a reload.

Requesting access to a screening​

  1. 1The user selects the key icon at the end of the screening's row. The Request Access dialog opens.
  2. 2The user may enter a Reason for request (optional, up to 1,000 characters), such as the user's role for the dam, and selects Send Request.
  3. 3DST confirms "Access request sent. The screening Facilitator will review it." The screening moves to Pending access requests, and the Facilitator receives a notification and an email.
  4. 4The Facilitator, or an administrator, approves or denies the request from the screening's management page. Approval grants Viewer access; either way, the user receives a notification and an email.

A request cannot be withdrawn from the Dashboard. After a denial the screening returns to the browse list and the user may request access again. A request for a screening with status Needs Facilitator waits until a Facilitator is assigned.

Creating a Screening​

Any signed-in user can create a screening. The user selects + New Screening on the My Screenings tab, selects Create Your First Screening on an empty Dashboard, or presses the n key from anywhere on the Dashboard. The New Screening dialog opens with every field empty. Figure shows the dialog completed for a dam taken from the National Inventory of Dams (NID), and Table describes each field.

Table: New Screening fields
FieldRequiredDescription
TypeRequiredOfficial or Testing (see My Screenings).
Screening NameRequiredUp to 200 characters, for example "FY26 Screening — Example Dam".
DamRequiredThe dam being screened, found in the NID or entered by name (see Choosing the dam).
USACE FacilitatorConditionalAppears only for an Official screening of a USACE dam (see USACE dams).
Vertical DatumRequiredNAVD88, NGVD29 or Other; Other adds a box for the datum name (up to 50 characters).
UnitsRequiredUS Customary or SI (Metric). A dam taken from the NID is fixed at US Customary.
DescriptionOptionalThe purpose of the screening, up to 2,000 characters.

Create stays unavailable until every required field is complete and the dam's NID record has finished loading. Vertical Datum and Units cannot be changed after the screening is created.

Selecting Testing as the Type adds the note "Testing screenings are for practice and cannot be submitted for review or produce official reports." and removes the USACE Facilitator requirement (Figure). The same figure shows the datum name box that appears when Vertical Datum is Other.

Choosing the dam​

The Dam field searches the NID as the user types, by dam name, state, NID ID or county. Each match shows the dam's Federal ID and name with its county and state beneath. The last choice in the list is always Use "…" as entered, for a dam that is not in the NID (Figure).

  • Selecting an NID dam links the screening to that NID record. The field shows the dam name followed by "— NID linked", DST loads the dam's NID record ("Loading NID data..."), and Units is fixed at US Customary. On Create, DST copies the dam's NID data into the screening.
  • Selecting Use "…" as entered, or leaving the field with text typed and nothing selected, creates a dam entered manually. DST notes that the screening will not be linked to the NID and that the dam information will be entered manually (Figure).

The × on the dam chip clears the selection. If the search finds nothing, the list reads "No NID matches found." and offers only Use "…" as entered. If the NID cannot be reached, DST reports "The National Inventory of Dams is currently unavailable. Please try again later."

USACE dams​

An Official screening of a dam owned by USACE needs a USACE Facilitator. When the user selects a USACE dam from the NID, the USACE Facilitator field appears (Figure). It searches the members of the USACE Facilitators group by name or email; the user selects a person, and Change replaces the selection.

The selected Facilitator becomes the screening's Facilitator and is notified, and the user who created the screening joins its team as a Team Member. For every other screening — any non-USACE dam, and any Testing screening — the user who creates it becomes its Facilitator. If the USACE Facilitators group has no members, DST reports "No USACE Facilitators available. Contact your administrator." and the screening cannot be created until an administrator adds one.

After the screening is created​

DST opens the new screening's Screening Information page. No confirmation message appears. Every new screening starts with two review levels, Level 1 and Level 2. DST also begins collecting background data for the dam — reservoir data for the stage-duration curve, and seismic hazard data where the dam's location supports it — which may take a few minutes to appear on the Hazards pages.

Managing Screenings​

Managing the screening team​

Manage Team in a screening's row actions opens the Manage Team dialog (Figure). It is available to the screening's Facilitator and to administrators.

  • Facilitator — shows the screening's Facilitator. An administrator can select Replace to assign a different Facilitator while the screening is In Progress or Testing. The previous Facilitator loses access to the screening.
  • Team Members — lists the screening's Team Members and Viewers. The role drop-down switches a person between Team Member and Viewer, and the remove icon removes the person from the screening.
  • Add Member — searches active users by name or email. The user chooses the role in the drop-down beside the search box and selects + Add as Team Member or + Add as Viewer on the person.

Every change in this dialog takes effect immediately, with no confirmation step, and DST confirms each one. Reviewers are not managed here; they are assigned to each review level on the screening's Review page.

While a screening is under review, Team Members and Viewers can still be added and removed, but the Facilitator stays fixed. Once a screening is Complete, or while it needs a Facilitator, only Viewer access can be changed. The dialog states which of these applies.

Copying a screening​

Copy creates a new screening from an existing one. Anyone on the screening can copy it. The Copy Screening dialog names the copy "(Copy)" followed by the original name and asks for its Type, which defaults to the original's. The user becomes the Facilitator of the copy, except for an Official copy of a USACE dam, which needs a USACE Facilitator as described in USACE dams.

A copy carries over the screening's name, description, vertical datum, units and dam information. It does not carry over hazards, dam information entered on the Dam Information pages, failure mode screening, selection or evaluation, consequences, risk analysis, Major Findings, documents, the screening team, or review history, and the dam data in the copy is unverified. The copy starts with its own Level 1 and Level 2 review levels and opens on its Screening Information page.

Renaming a screening​

Rename opens a dialog with the screening's current name. The user edits the name (up to 200 characters) and selects Rename; DST confirms the new name. A screening can be renamed only while it is In Progress or Testing. If another user changed the screening at the same moment, DST reports that the page was refreshed and the rename is not applied; the user renames it again.
