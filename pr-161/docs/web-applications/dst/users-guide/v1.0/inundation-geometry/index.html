Dam Screening Tool

Inundation Geometry

The flood simulations of the Inundation Analysis page run on the hydraulic model defined on the Inundation Geometry page (Consequences > Inundation Geometry). The model consists of the area it covers, the dam, the rivers and other lines that shape the mesh, the terrain and land cover, and the computational mesh built from them.

Figure shows the page with the dam centerline selected, and Table describes each numbered region.

Table: Inundation Geometry page regions
#RegionDescription
Add buttonsAdd a feature of each type, or replace the model area, dam centerline, terrain or land cover. Mesh computes the mesh.
SearchFilters the tree by feature name.
TreeThe mesh status and cell count, then the features by type. Selecting a feature selects it on the map.
Map toolbarThe map tools (see The map).
Properties panelThe selected feature's fields and summaries.
Status stripThe pointer position and a hint for the current tool or selection.

The Model Configuration panel holds the add buttons, a Search features… box and a tree of the model's features. Resting the pointer on an add button gives the feature's full name. A screening has one model area, one dam centerline, one terrain and one land cover; once one exists, its button replaces it ("Replace the …"). A warning icon in the tree marks a feature whose settings are incomplete or invalid; resting the pointer on it gives the reason. Selecting a feature opens its [Feature] Properties panel.

Building the Model​

The steps below build a model that is ready to simulate:

  1. 1Add the Model Area, the polygon the mesh covers (see Model Area).
  2. 2Add the Dam centerline along the dam crest (see Dam Centerline).
  3. 3Optionally, add River centerlines, Coastlines, Breaklines and Refinement regions to shape the mesh.
  4. 4Add the Terrain and the Land Cover, and wait for each to finish processing.
  5. 5Select Mesh and review any mesh warnings (see Computational Mesh).

The Inundation Analysis page refuses to run until the model has a drawn model area, a computed mesh, a terrain and a land cover (see Common Problems).

The Map​

Every page of the Consequences module except Consequence Analysis and Results Data is a map. The map toolbar changes the map style, identifies the features under the pointer (Identify features), measures distances, zooms in, out and to all layers, resets the bearing to north and exaggerates the terrain. When an editable feature is selected, the toolbar adds Edit selected feature, and while editing, Save edits, Cancel edits (Escape) and Add points. The status strip gives the pointer's longitude, latitude and zoom, and a hint for the current tool, such as "Click a feature to select".

The layers button opens the legend, which turns the layers on and off in the groups Inundation Geometry, Consequence Data, Inundation Results and Reference Layers (USGS rivers and lakes, and the levees of the National Levee Database). DST remembers which layers are on for each page during the session. Below zoom 13 the map shows only a sample of the structures; zooming in shows every one.

Identifying Features​

With Identify features on, selecting a point on the map lists every feature under it, grouped by type, such as the model area, the rivers and the Structures. Selecting a structure's row opens its attributes; selecting any other row selects that feature. Resting the pointer on a row highlights its feature on the map, which tells overlapping features apart. Large groups list 50 rows at a time, with Show [N] more.

Below zoom 13 the list holds only the sampled structures, and notes "Below zoom 13 the map shows a sample of the structures. Zoom in to list every one here."

Structure Symbology​

The structure layer's style editor in the legend sets how the structures are drawn on every page of the module. Color by chooses what colors them: Damage category (the default), Occupancy class, Building type, Foundation type, Foundation height, Stories, Structure value, Total value, Day population, Night population, LifeSim data checks or Single color. The legend lists the classes with the number of structures in each.

  • From zoom 13, Damage category draws each category as its own shape: a house for Residential, a square for Commercial, a triangle for Industrial and a diamond for Public.
  • Total value is the structure, content and vehicle values together; the populations are the under-65 and 65-and-over counts together.
  • LifeSim data checks colors each structure by its most serious problem: Outside the Emergency Response area, Missing population, Missing building data, Missing values or Unusual population, or No problems found (see Structure Inventory).

The style editor also sets the symbol size, outline, opacity and marker, and each class can be edited on its own. DST keeps these choices across the pages of the module until the page is reloaded.

Adding a Line or Area​

The model area, dam centerline, river centerlines, coastlines, breaklines and refinement regions are added through one dialog, titled with the feature's name:

  1. 1Select the feature's add button and enter its fields (listed in the sections below).
  2. 2Optionally, select Import Geometry from File to read the outline from a GeoJSON (.geojson, .json) or KML (.kml) file. A river can instead be selected with Pick a River on the Map, and a breakline with Pick a Levee on the Map or Pick a Road on the Map.
  3. 3Select Create (or Replace).
    Result: When no geometry was given, DST creates the feature and starts the map's drawing tool for it at once.
Requires

A model area, before a line can be selected from the map.

A river selected from the map comes from USGS NHDPlus V2, a levee from the USACE National Levee Database and a road from OpenStreetMap; only the stretch inside the model area is kept. Before the line is added, a preview shows its length and any notes, such as "It was trimmed at the dam: only the stretch downstream of the dam is kept.", with Pick Again and Use This River, Use This Levee or Use This Road. With the reference layers on, selecting a river or levee on the map also offers Import as River Centerline or Import as Breakline.

The model area is the polygon the mesh covers. Table lists its fields.

The dam centerline is the line along the crest of the dam where the breach or dam hydrograph enters the mesh. Table lists its fields.

Table: Dam centerline fields

River Centerlines​

A river centerline is meshed as one row of rectangular cells along the river. A river that enters the model area from outside can take an inflow on the Inundation Analysis page. Table lists its fields.

Table: River centerline fields
FieldUnitsRequiredDescription
Name—RequiredA descriptive name for the river centerline.
Bankfull WidthftRequiredThe width of the river at its bankfull stage. Defaults to 50. Must be greater than zero.
Manning's n—RequiredThe roughness of the river channel. Defaults to 0.035. Must be greater than zero; values above 1 are flagged as atypical.
River Cell SizeftOptionalThe cell length along the river. Blank uses three times the bankfull width.
Centerline summary—Read-onlyLength, estimated cells and vertices.

Coastlines, Breaklines and Refinement Regions​

A coastline is a line along the model area's edge where a stage boundary can be applied. A breakline aligns the mesh with a sharp change in elevation, such as a levee, embankment or road. A refinement region is a polygon meshed at a smaller cell size. Table lists their fields.

Table: Coastline, breakline and refinement region fields
FieldUnitsRequiredDescription
Name—RequiredA descriptive name for the feature.
Cell Size near Coastline, Cell Size near BreaklineftOptionalThe mesh cell size next to the line. Blank applies no refinement.
Cell Size (refinement region)ftOptionalThe mesh cell size inside the region. Blank uses the model area cell size.
Summary—Read-onlyLength or area, estimated cells and vertices.

Terrain​

The terrain supplies the ground elevations of the mesh. Terrain opens the Add Terrain dialog, with two tabs:

  • OpenTopography downloads a terrain over the model geometry with a 660 ft (200 m) buffer. The Dataset is Copernicus 30m (COP30, the default) or 90m (COP90), SRTM 30m (SRTMGL1) or 90m (SRTMGL3), or USGS 1m, 10m or 30m (3DEP, United States only). A Download Area preview shows the area to be requested. One download covers at most 4° of latitude or longitude, 1.5 billion cells and 40 requests. Download starts it, and it continues after the dialog closes.
  • Upload File reads a GeoTIFF (.tif, .tiff) digital elevation model up to 11 GB, chosen with Select GeoTIFF File. Elevation Units (Meters or Feet) is required; meters are converted to feet.

Name is optional; a blank name is generated. While the terrain processes, its row shows a spinner, and DST reports "Terrain "[name]" is ready!" when it finishes. Its properties panel shows its source, resolution, units, dataset and bounding box, and warns when the model geometry extends past the terrain.

caution

Replacing a downloaded terrain deletes the old one when the download starts. If the download fails, the model has no terrain until another is added.

Land Cover​

The land cover sets the roughness (Manning's n) of the floodplain. Land Cover opens the Add Land Cover dialog, with two tabs:

  • NLCD downloads the National Land Cover Database over the model geometry with a 660 ft buffer. NLCD Year is Latest available (the default) or a release from 2021 back to 2001.
  • Upload File reads a GeoTIFF of whole-number land cover classes. NLCD codes keep their NLCD names and Manning's n; any other code becomes "Class N" with n = 0.06 until it is set.

The properties panel shows the land cover's source, year, resolution and bounding box. Edit Manning's n… opens the Manning's n by Land Cover Class dialog, which lists each class's Code, Land Cover Class, Default n and Manning's n. Each Manning's n is greater than 0 and at most 1. Reset to defaults restores the defaults and Save keeps the changes. Changing a value marks existing simulation results as out of date. Where the model extends past the land cover, the mesh uses a Manning's n of 0.06.

Computational Mesh​

Mesh computes the computational mesh from the model geometry; selecting it again while the mesh computes cancels it. The status under Model Geometry reads "Queued…", a percentage, "[N] cells", "[N] cells · [K] warnings", "Failed", "Cancelled" or "Not computed".

Requires

A model area with a drawn boundary, before the mesh can be computed.

When the mesh fails or has warnings, the Mesh failed or Mesh warnings card opens over the map. It lists each message from the mesher with Show on Map, which outlines and zooms to the problem.

note

DST does not recompute the mesh when the geometry changes. The user selects Mesh again after changing the geometry or the dam's mesh settings.

Editing, Saving and Downloading Geometry​

The fields in a properties panel save when the user leaves the field (see Saving). Outlines are edited explicitly:

  • Edit Geometry in the properties panel, or Edit selected feature in the toolbar, starts an edit, and Save or Cancel ends it; Esc cancels.
  • Switching features with unsaved edits asks "Discard Unsaved Changes?" (Keep Editing or Discard Changes), and leaving the page asks for confirmation (Stay or Leave Page).
  • The trash icon in the properties panel deletes a feature after confirmation.

Each feature downloads as GeoJSON from its tree row or panel, and the terrain and land cover as their files. The Model Geometry download saves all the geometry as one GeoJSON file, with the mesh (.h5, .hdf) once it is computed.

Changes to the geometry, terrain, land cover or mesh do not clear later results. DST marks the inundation and consequence results that depend on them as out of date until they run again.

Common Problems​

  1. The dialog reads "No download area available." or "No bounding box available." until the model has geometry. The user adds the model area, or another feature with geometry, first.

  2. DST reports "Terrain failed: [reason]" or "Land cover failed: [reason]". The user adds it again, or uploads a file instead. When a service the dialog depends on is down or degraded, the tab shows the outage's site alert at the top (see Site alerts); the download or upload can still be started, but may fail until the service recovers.

  3. The terrain's properties panel warns that part of the model has no ground elevations, and the Inundation Analysis page refuses to run. The user downloads a terrain again to cover the model, uploads one that covers it, or moves the model area inside the terrain.

  4. Show on Map in the Mesh failed or Mesh warnings card finds each problem. The user adjusts the geometry or cell sizes there and selects Mesh again.

  5. DST does not recompute the mesh automatically. The user selects Mesh again, then runs the analysis again.
