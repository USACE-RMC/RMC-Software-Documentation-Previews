Dam Screening Tool

PFM-10: Foundation Backward Erosion Piping

In potential failure mode 10 (PFM-10), seepage under the embankment exits downstream, erodes a foundation sand layer at an unfiltered exit, and a pipe works back toward the reservoir: backward erosion piping in the foundation. The loading is the reservoir (headwater). On the PFM-10 page, the user characterizes the foundation sand, any confining layer, the seepage path, the pipe roof support and the observed seepage at a location in eight numbered sections, and DST calculates the system response probability (SRP) curve. Failure Mode Pages and System Response describe the parts that every failure mode page shares.

The user opens a PFM-10 location from Response > Failure Mode Evaluation (see Opening a Location). The page heading reads 10 - Foundation Backward Erosion Piping. The answers in section 1 decide which inputs the later sections show. To evaluate a location:

  1. 1Select the embankment cross section in Cross Section, with any seepage berm drawn on it.
  2. 2In section 1, answer Confining layer and Upstream engineered blanket.
    Result: Sections 2 through 8 show only the inputs that apply.
  3. 3Complete sections 2 through 8.
  4. 4Review the SRP curve, revise nodes if needed, and verify the location.

Figure shows the top of the page, and Table describes each numbered region.

Table: PFM-10 page regions
#RegionDescription
Page headingThe failure mode number and name.
LocationThe location name (see Location and Cross Section).
Cross SectionThe embankment cross section the location evaluates.
SRP modeDST Based SRP or User Defined SRP (see User-Defined SRP).
Feature tilesThe confining layer and upstream blanket answers (see Failure Pathway Characterization).
SchematicThe seepage system drawn from the cross section (see Seepage System Schematic).
Numbered sectionsSections 2 through 8 of the characterization, starting with Foundation Sand Continuity.

Inputs on this page save automatically (see Saving). Results recalculate automatically when an input changes (see Automatic Calculation). Changing an input clears the location's verification (see Verifying a Location). The information buttons in each section define every category.

Location and Cross Section​

Each PFM-10 location evaluates the foundation on one cross section. The user adds, copies, renames and deletes locations as described in Locations; a copy keeps every input of the original. Table lists the toolbar inputs (see also The Page Toolbar).

Table: PFM-10 toolbar inputs
FieldUnitsRequiredDescription
Location—RequiredThe location name. Saves when the user leaves the box. A blank name is rejected with "Name cannot be empty."
Cross Section—RequiredThe embankment cross section through the foundation reach. Only embankment (earth) cross sections from the Dam Information page are listed. Its geometry, materials and any drawn seepage berm feed the schematic, the berm section and the pipe roof materials.
SRP mode—RequiredDST Based SRP (default) shows the sections below; User Defined SRP replaces them with the user-defined SRP grid.

Failure Pathway Characterization​

Section 1, Failure pathway characterization, identifies the physical features that shape the seepage pathway. Its two answers decide which inputs the later sections show and what the model assumes. Table lists them.

Table: PFM-10 failure pathway features
FieldUnitsRequiredDescription
Confining layer—RequiredYes, No or Unknown: whether a natural layer of low-permeability soil lies over the foundation sand, beneath and downstream of the embankment. A confirmed layer creates a daylight exit at its downstream end. Unknown keeps both the toe and daylight exits in the analysis. Sets what sections 4, 5, 7 and 8 show.
Upstream engineered blanket—RequiredYes or No: whether a constructed impervious blanket lies on the reservoir floor upstream of the dam. Its length sets the upstream seepage path. Sets what section 5 shows.

Seepage System Schematic​

The schematic draws the embankment and any seepage berm to scale from the selected cross section, with schematic foundation layers and the toe, berm-toe and daylight exits that apply. Its caption ends with a link to the Dam Information page, where the section is drawn. Without a selected cross section it shows a placeholder.

After the user scrolls past the schematic, a small copy of it stays in view at the top of the page; it does not appear on narrow screens. The pointer resting on the copy enlarges it and lists readings that summarize the answers: Exits, Continuity, Foundation sand, Confining layer, Path length, Pipe roof and Seepage. A reading shows "Awaiting answer" (or the answer it waits for) until its section is answered. Selecting the copy keeps it open until the user selects the × button, presses Escape or selects elsewhere. Figure shows the enlarged copy.

tip

Selecting a reading in the enlarged schematic moves the page to the section that sets it, so the schematic serves as an efficient way to locate and complete an unanswered input.

Foundation Sand Continuity​

The likelihood of a continuous foundation sand layer is estimated in section 2, Foundation sand continuity. The geologic environment sets a starting probability, and subsurface data, when available, adjusts it. Table lists the inputs. An interpretation panel describes each selected category; with no subsurface data it reads "No subsurface data is available, so the geologic environment alone sets continuity."

Table: PFM-10 foundation sand continuity inputs
FieldUnitsRequiredDescription
Geologic environment—RequiredGlacial outwash, High-energy fluvial systems, Coastal shoreface / barrier systems, Aeolian dune systems, Delta deposits, Alluvial fans, Shallow marine shelf, Low-energy deltaic and coastal mud systems, Residual soils or Unknown. Starts at "Select...".
Can subsurface data inform sand continuity?—RequiredYes or No: whether borings, CPTs or test pits can support or weaken the geologic case for a continuous sand layer.
Strength of evidence for continuity—Conditional: subsurface data is YesA slider from Very strong through Strong, Moderate, Neutral and Weak to Very weak. Disabled unless subsurface data is Yes.
Subsurface data quality—Conditional: subsurface data is YesA slider of High, Moderate or Low. Disabled unless subsurface data is Yes.

Foundation Sand Characterization​

Section 3, Foundation sand characterization, describes the sand layer. Table lists the inputs, and an interpretation panel describes the selected categories. Parameter Overrides describes entering a distribution.

Table: PFM-10 foundation sand inputs
FieldUnitsRequiredDescription
Foundation sand thickness, DfftRequiredA distribution: Deterministic, Uniform, Triangular, PERT or Normal, with its parameters, one decimal. Starts at Deterministic with no value. Drives the uplift check at the exit and the progression calculation.
Fines content—Required< 5%, ≥ 5% or Unknown. At 5% fines or more the critical gradient for hydraulic progression is increased by a factor of 1.4; below 5%, or unknown, no correction is applied.
Field relative density category—RequiredVery loose, Loose, Medium dense, Dense, Very dense, Unknown or Custom distribution. Each category sets a Uniform range of relative density: 0–15%, 15–35%, 35–65%, 65–85%, 85–100%, and 15–65% for Unknown. Custom distribution opens the overrides tray for a site-specific distribution.

Advanced material property overrides below the section opens a tray of material properties: "Defaults stay shown and locked until you choose a site-specific distribution." Each card starts at Default and also offers Deterministic, Uniform, Triangular, PERT and Normal. Table lists the cards.

Table: PFM-10 foundation sand overrides
FieldUnitsRequiredDescription
Field relative density, Dr%Conditional: Custom distributionShows the category's Uniform range, locked. With Custom distribution the tray opens and the card takes a site-specific distribution between 0 and 100%; Normal distributions are cut off at 0 and 100%.
Sand saturated unit weight, γspcfOptionalDefault: Normal, mean 122.0, standard deviation 3.0.
Coefficient of uniformity, Cu—OptionalDefault: Triangular, minimum 1.1, most likely 2.0, maximum 4.0.
Grain size (10% finer), d10fmmOptionalDefault: Normal, mean 0.25, standard deviation 0.085.

Confining Layer​

The natural layer over the foundation sand is described in section 4, Confining layer, whose content depends on the Confining layer answer in section 1. Before that is answered the section reads "Answer whether a confining layer is present in section 1." With No it reads "Confining layer not present" and "Thickness, permeability, and layer extent are not evaluated." With Unknown it lists the "Model assumptions": thickness Uniform 0–10 ft, permeability Unknown, the downstream extent (the berm length, or "Uniform, 1H to 5H"), and the daylight exit ground when it is the berm toe. With Yes it shows the inputs in Table.

Table: PFM-10 confining layer inputs
FieldUnitsRequiredDescription
Permeability—RequiredImpervious, Semi-pervious or Unknown. Decides whether the layer resists blowout and whether its upstream extent can lengthen the seepage path. Help text: "Unknown uses the screening model's default permeability."
Thickness category—RequiredVery Thin (0–5 ft), Thin (5–10 ft), Moderate (10–20 ft), Thick (20–35 ft), Unknown (0–10 ft) or Custom distribution. Each category is a Uniform range; Custom distribution opens the overrides tray.
Daylight exit ground elevationftOptional; also shown for UnknownThe ground elevation at the downstream end of the confining layer, used as the exit elevation in the progression check. Two decimals. Help text: "Blank uses the embankment toe elevation." ("berm toe" with a seepage berm). When the layer ends at the berm toe, a read-only "Daylight exit ground" reading replaces the box.
Is the downstream confining layer extent known?—RequiredKnown or Unknown. Unknown shows the "Assumed downstream extent" notice: the berm length with a seepage berm, or 1 to 5 times the embankment height, uniformly distributed.
Downstream confining layer extentftConditional: extent is KnownHow far the layer extends beyond the downstream embankment toe, at least 0.1, one decimal. With a seepage berm the greater of this and the berm length is used.

The section's Advanced material property overrides tray holds Confining layer saturated unit weight, γb (pcf, default Normal, mean 118.0, standard deviation 3.0) and, with Yes, Thickness, zb (ft), which shows the category's Uniform range locked and takes a site-specific distribution when the thickness category is Custom distribution; the tray opens automatically in that case.

Upstream Seepage Path​

Section 5, Upstream seepage path, sets the length the seepage path gains upstream of the embankment. Its content depends on the section 1 answers and the confining layer permeability, as shown in Table.

Table: PFM-10 upstream seepage path inputs
FieldUnitsRequiredDescription
Engineered blanket lengthftConditional: blanket is YesThe horizontal distance from the upstream embankment toe to the blanket edge, at least 0.1, one decimal.
Does the confining layer extend beneath the reservoir?—Conditional: no blanket and an impervious confining layerYes, No or Unknown. No and Unknown add no upstream length, with the notices "No upstream length added" and "Upstream extent unknown". For a Very Thin layer, Yes shows "No length added for a very thin layer".
Upstream confining layer extentftConditional: extension is YesThe extent measured from the upstream embankment toe to the end of the layer, at least 0.1, one decimal. Not used for a very thin layer.

Without a blanket and with a confining layer that cannot add length, the section shows "No upstream length added" with the reason, for example "Only an impervious confining layer can add upstream length." While the confirmed layer's permeability is not chosen it reads "Choose the confining layer's permeability first. Only an impervious layer can lengthen the seepage path." Before the blanket is answered it reads "Answer whether an upstream engineered blanket is present in section 1."

Downstream Seepage Berm​

Section 6, Downstream seepage berm, is read-only. It shows the seepage berm drawn in the selected cross section on the Dam Information page; to change it, the user edits the berm there (see Berm Tab). With a berm it shows Berm length from downstream embankment toe (ft) and Berm-toe ground elevation (ft), and a "Drawn berm geometry is incomplete" notice when the berm has no usable length. Without one it shows "No drawn seepage berm"; without a usable cross section it shows "Cross section required".

Pipe Roof Support​

What supports the roof of a developing pipe is set in section 7, Pipe roof support. With a confining layer (Yes) it reads "The confining layer supports the pipe roof" and "No embankment material needs to be selected." With No or Unknown it shows Materials that can support the pipe roof, a card for each material of the selected cross section with its material type ("Type not assigned" when none). The defaults, marked "(Default)", are the materials along the embankment base, and they start selected. The user selects or clears cards; at least one is required. Any other selection is an override (see Characterization). When no material qualifies, the section reads "No materials in the cross section can support a pipe roof yet." with a link to the Dam Information page.

Observed Performance​

Section 8, Observed performance, records downstream seepage evidence and the pool conditions under which it occurred. Table lists the inputs.

Table: PFM-10 observed performance inputs
FieldUnitsRequiredDescription
Have downstream seepage indicators been observed?—RequiredYes or No. Seepage observations raise or lower the likelihood of a continuous seepage path.
Observation type—Conditional: seepage observedSand boils, Concentrated seepage, Stage-dependent wet areas or Stage-independent wet areas. Starts at "Select...".
Lowest pool elevation with seepageftOptional; shown for sand boils or concentrated seepageThe lowest pool at which the seepage was seen, greater than zero and not above the crest, two decimals. Help text: "At and above this elevation, initiation is certain."
Does the seepage occur through the confining layer?—Conditional: sand boils or concentrated seepage, and the toe exit geometry appliesYes or No. When the question does not apply, a notice gives the reason, for example "Not needed without a confining layer" or "Not used for this geometry".

System Response​

The System Response section shows the PFM-10 SRP curve, its table and the seven nodal tables (see SRP Charts and Nodal Tables). When the seepage system has a daylight exit as well as the toe exit, DST evaluates two exit pathways, and the section reads "Two exit pathways are evaluated — the toe path and the daylight exit. The governing curve is the per-pool maximum of the two." The table then has the columns Headwater Elevation (ft), Toe Pathway, Daylight Pathway and Governing; with a single exit it has Headwater Elevation (ft), DST Estimate and Revised Estimate. Figure shows the two-pathway table and chart with the nodal tables expanded and one node revised.

Download SRP curves as a CSV file exports the curves, and Copy SRP curve data for spreadsheets copies them for pasting into a spreadsheet. The collapsed Nodal System Response section holds the nodal tables listed in Table. With two exit pathways, the nodes that depend on the exit show a Toe and a Daylight value, and a revision is entered for each pathway. Revert to DST Estimates appears once a node is revised. Nodal Revisions describes revising a node, and Calculation Currency describes the notice about out-of-date results.

The location's verification appears as "PFM-10 SRP —" followed by the location name (see Verifying a Location).

User-Defined SRP​

With User Defined SRP selected, the page replaces the characterization and system response sections with a grid of headwater elevations and probabilities and its chart. User-Defined SRP and Active SRP describe the grid and switching between modes.

Failure Mode Summary​

The Failure mode summary tray at the bottom of the page (see Failure Mode Summary) lists under Unknowns each PFM-10 input answered Unknown and how DST treats it, as shown in Table. Its Parameter overrides section lists the pipe roof materials and each overridden distribution, and its Nodal revisions section names the pathway of each revision ("Single path", "Toe" or "Daylight").

Table: PFM-10 unknown inputs
InputHow DST treats it
Geologic environmentTreated the same as "Alluvial fans" and "Shallow marine shelf".
Confining layer presenceTreated as a layer that may be present. The model assumes a uniform thickness of 0–10 ft (0–3 m) and checks both the toe and daylight exits.
Confining layer thicknessThe model assumes a uniform thickness of 0–10 ft (0–3 m).
Confining layer permeabilityTreated the same as "Semi-pervious".
Confining layer extends upstreamTreated the same as "No": no upstream length is added to the seepage path.
Downstream confining extentThe model assumes the layer extends a uniform 1 to 5 embankment heights beyond the toe, or to the berm toe when a berm is present.
Foundation sand relative densityThe model uses a uniform distribution of relative density between 15% and 65%.

Common Problems​

Problems every failure mode page shares, such as a system response that does not calculate, no usable cross sections, a deleted cross section or a refused verification, are described in Common Problems on the Failure Mode Pages page. This page adds its own.

  1. The later sections wait for the section 1 answers. The user answers Confining layer and Upstream engineered blanket in section 1.

  2. Both sliders apply only to subsurface data. The user answers Yes to Can subsurface data inform sand continuity? in section 2.

  3. Field relative density, Dr and Thickness, zb follow their category. The user chooses Custom distribution in Field relative density category or Thickness category; the tray opens and the card takes a site-specific distribution.

  4. The user chooses the Permeability in section 4. Only an Impervious confining layer adds upstream length.

  5. The berm drawn in the cross section has no usable length. The user completes it on the Berm tab of the cross-section editor (see Berm tab).

  6. A selected material changed or was removed on the Dam Information page, and DST cleared the selection, the results and the verification. The user selects the materials again in section 7.

  7. The user assigns the material type on the Dam Information page, or clears that card in section 7.

  8. The user corrects the parameters on that card (see Parameter overrides).
